## Using these pages

Read the explanation, discuss the diagram, predict the example, and complete your teacher's chosen workbook task. Record actual results and explain changes. Supplied code can use supporting blocks without every detail becoming a learning objective. Functions are taught as named groups of instructions that can be defined, called and reused.
